# tree-sitter-yaml

[![CI](https://github.com/konomanoasa/tree-sitter-yaml/actions/workflows/ci.yaml/badge.svg)](https://github.com/konomanoasa/tree-sitter-yaml/actions/workflows/ci.yaml)

[![npm](https://img.shields.io/npm/v/@konomanoasa/tree-sitter-yaml)](https://www.npmjs.com/package/@konomanoasa/tree-sitter-yaml)

[Tree-sitter](https://tree-sitter.github.io/tree-sitter/) grammar for
YAML Ain't Markup Language 1.2.2.

## Installation

```sh
npm install @konomanoasa/tree-sitter-yaml
```

## Development

Development uses Node.js 24.21.0 or later.

```sh
npm install
npm run build
npm test
```
